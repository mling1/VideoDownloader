# VideoDownloader

> MSE 流媒体视频捕获与无损合成下载工具（Tampermonkey 油猴脚本）

通过劫持 MediaSource Extension（MSE）的 `SourceBuffer.prototype.appendBuffer`，被动捕获网页播放器投喂的音视频 fMP4 分片，再用 mp4box.js 无损合成为**单个可正常播放、可拖动进度条、有声的 MP4 文件**。

---

## 功能特性

- **全站点通用**：支持所有使用 MSE 播放流媒体的网站（B 站、腾讯视频、优酷、抖音等）
- **无损合成**：容器级 remux，不重新编码，画质音质无损；输出普通 MP4，支持进度条拖动
- **智能锁定**：完整捕获标橙锁定，大跳转标红锁定，防止不连续内容混入导致音画不同步
- **自动完整下载**：一键完成静音→16倍速→隐藏画面→从头播放→完整捕获→自动合成→自动下载
- **m3u8 下载**：页面注入在线 m3u8 下载工具，支持范围下载、原格式下载、转码 MP4 下载

## 使用说明

打开视频网站，页面右上角会出现蓝色控制面板。

### 下载已捕获片段 (N)

将当前已捕获的分片无损合成为 MP4 下载。未完整加载时文件名自动加 `_片段` 后缀。

### 倍速控制

短按在 1×→2×→4× 间循环，长按切换 16×，加速视频加载。

### 跳至结尾 / 跳至开头

一键跳到结尾触发剩余分片加载（执行前自动标红锁定）；已在结尾时按钮变为「跳至开头」。

### 自动完整下载（推荐）

一键完成全流程：静音→16倍速→隐藏画面→从头播放→完整捕获→自动合成→自动下载。过程中可再次点击暂停取消。

### m3u8 下载

页面右下角弹出在线 m3u8 下载工具，支持：
- **特定范围下载**：下载指定片段范围
- **原格式下载**：下载原始 MPEG-TS 格式（.ts，兼容性最好）
- **转码为MP4下载**：拼接后转码为 MP4

## 片段数颜色说明

| 颜色 | 状态 | 说明 |
|------|------|------|
| 白色 | 捕获中 | 视频正在播放/缓冲，分片逐步捕获 |
| 橙色 | 完整捕获 | 视频已完整加载，片段已锁定 |
| 红色 | 大跳转锁定 | 向前跳转或向后跳转超出缓存，下载可能出现音画不同步 |

## 常见问题

**Q: 捕获不到分片？**
A: 刷新页面让脚本在页面加载时注入，然后点击播放视频。

**Q: 下载的视频没有声音/无法拖动？**
A: 尝试用「自动完整下载」从头完整捕获。不完整片段可能存在这些问题。

**Q: 支持哪些网站？**
A: 所有使用 MSE 播放流媒体的网站。不支持纯 m3u8 直链、WebRTC 直播、DRM 加密视频。

## 技术原理

1. **捕获层**：`document-start` 注入，劫持 `SourceBuffer.prototype.appendBuffer`，复制保存每次投喂的 fMP4 分片
2. **分类层**：按 MIME 或 init segment 的 hdlr box 自动识别音视频轨
3. **合成层**：用 mp4box.js 解析 fMP4 流，提取所有样本，手动构建普通 MP4 的 sample table，输出非 fragmented MP4
4. **容错处理**：截断不完整的末尾 box；解析错误时用已解析样本继续完成合成
